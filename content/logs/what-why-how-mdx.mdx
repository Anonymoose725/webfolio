## What is MDX?

According to [their documentation](https://mdxjs.com/docs/what-is-mdx/), MDX is modern file format which
*"allows you to use JSX in your markdown content."*

Here's a small sample below to confirm the syntax is working

```ts
const isWorking = true;
```

## Why MDX?

MDX allows me to take advantage of both the simplicity and formatting of markdown files and the customization and
flexbility of react components, while being native to this webapp.
